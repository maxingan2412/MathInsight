# 同构变式题标准

本文规定数鉴（MathInsight）里「同构变式题」指什么、相似度怎么把握、生成后怎么检验。`mathinsight/variants.py` 按本标准拼提示词和做检验。目前标准已定，题库里还没有批量生成的变式题；具体到某道题时再按本标准生成和调整。

## 1. 一道题的四层

| 层 | 内容 | 例：2024 新课标Ⅰ卷第 6 题 |
|---|---|---|
| ① 表面 | 数字、字母、情境 | 各项系数 |
| ② 结构 | 研究什么对象、条件怎么给、问什么 | 分段函数在 $\mathbf R$ 上递增，求参数范围 |
| ③ 题眼 | 卡在哪一步、靠什么转换想通 | 两段各自递增还不够，分界点处左段不能高过右段 |
| ④ 知识 | 教材小节 | 函数的单调性 |

## 2. 什么算同构变式

**保留第 ③ 层，更换第 ② 层，第 ① 层不限，第 ④ 层不超出原题的知识范围。**

- 只动第 ① 层（换数字、换字母）不算变式：学生照抄原题步骤就能做完。这类题只用作基础运算的重复练习。
- 第 ③ 层变了也不算：那是同一章里的另一道题。

## 3. 一条可检验的判据

> 原题的解题步骤逐步照抄会失败，但原题题眼里「打通」的那句话仍然用得上。

两半分别检验：

1. **照抄检验（防太像）**：拿原题的解答逐步替换去做新题。每一步都能照搬，判为太像，不要。
2. **题眼检验（防太不像）**：独立解新题并写出它的题眼，与原题题眼比较。卡点或打通对不上，判为太不像，不要。

## 4. 相似度三档

| 档 | 第 ② 层怎么换 | 例（原题同上） | 用途 |
|---|---|---|---|
| 近 | 只换结构里的一个要素 | 递增改递减；其中一段换成别的函数 | 巩固 |
| 中 | 换载体 | 改为「分段定义的数列是递增数列，求参数范围」：只看整数点，接口条件变成前一段末项小于后一段首项 | 巩固、拔高 |
| 远 | 换领域，想法相同 | 分段计费的应用题里求使费用单调的参数 | 拔高 |

「铺垫」题单列：不换结构，把卡点那一步拆成引导小问或直接给出。

## 5. 生成办法

1. **从题眼出发，不从题面出发。** 先看原题的题眼和本质，列出这个想法还能装进哪些结构（别的函数类型、数列、几何对象、正问改反问、已知结论求条件），再在选定的结构上命题。
2. **材料逐题不同，提示词通用。** 每道题提供：题干、答案、题眼（卡点与打通）、本质、题卡里写好的改编方向、教材小节。
3. **范例用真题。** 从题库里检索与原题同一考点的真题两三道放进提示词，让命题时看到同一考点在真题里换过哪些结构。题眼相同的真题对是最好的范例，题库按题眼归类后优先用它们。
4. **一次多出几道，再筛。**

## 6. 入库前的检验

按顺序做，任何一项不过就不入库：

1. 独立重解，答案与命题时给的答案一致。
2. 能计算的题（求值、求范围、计数、概率）用程序核对答案。
3. 照抄检验与题眼检验（第 3 节）。
4. 机械检查：条件自洽（定义域、判别式等）、不超出知识范围、与原题和题库已有题不重复。
5. 教师审定。
